# UTS_GAME_ADIT_AJWA_A1
ADVENTURE OF ENGLISH  v1.0
Game edukasi 3D untuk siswa SD - belajar kosakata Bahasa Inggris sambil bertualang.

CARA MENJALANKAN
1. Ekstrak seluruh isi zip ke satu folder (jangan jalankan dari dalam zip).
2. Klik dua kali AdventureOfEnglish.exe.
3. Jika muncul "Windows protected your PC": klik "More info" lalu "Run anyway".
   (Muncul karena game ini belum ditandatangani secara digital, bukan karena virus.)
Semua file di folder ini dibutuhkan - jangan dipisahkan dari .exe.

ALUR PERMAINAN
Main Menu > Start Game > pilih level (Classroom, Garden, Cafeteria)
1. Lewati jalur rintangan: lompati tumpukan benda, hindari benda yang bergerak dan genangan.
   Tersentuh? Kamu kembali ke checkpoint (bendera).
2. Di garis FINISH jawab 5 soal Bahasa Inggris. Lulus minimal 60 poin kuis.
3. Pintu EXIT terbuka - masuk ke pintu untuk menyelesaikan level.

KONTROL
W A S D / tombol panah ... bergerak
Shift (tahan) ........... lari
Space ................... lompat
E ....................... lihat benda (belajar kata baru)
Klik kanan + mouse, Z, C  putar kamera
1 2 3 / A B C ........... pilih jawaban kuis (atau klik)
Esc ..................... pause (Resume, Settings, Main Menu)

SKOR
Checkpoint +10, FINISH +20, jawaban kuis benar +20 (percobaan ke-2 +10). Maksimal 140 per level.

KOSAKATA
Classroom : Book, Pencil, Eraser, Ruler, Chair
Garden    : Flower, Tree, Butterfly, Grass, Bird
Cafeteria : Rice, Milk, Water, Bread, Apple

KEBUTUHAN SISTEM
Windows 10/11 64-bit, kartu grafis dengan DirectX 12. Diuji pada NVIDIA GTX 1650 (rata-rata 227 FPS di 1280x720).

Dibuat dengan Blender 5.1 (model & animasi) dan Unity 6 (gameplay).
Musik dan efek suara adalah placeholder sintesis.
